# 🛒 E-commerce Backend API

REST API for an e-commerce application built with Node.js, Express and MongoDB.

## 🚀 Features

- User authentication (JWT)
- Product management
- Cart functionality
- Purchase flow with ticket generation
- Pagination and filtering

## 🛠 Tech Stack

- Node.js
- Express
- MongoDB
- JWT Authentication
- Docker

## 📦 Installation

```bash
git clone https://github.com/Tojohtml98/ecommerce-backend-api
cd ecommerce-backend-api
npm install
npm run dev
